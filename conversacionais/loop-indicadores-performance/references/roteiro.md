# Análise de Indicadores e Performance

Roteiro do anexo fornecido por Rafael. Objetivos, instruções e prompts preservados; rótulos de interface removidos.

## Etapa 1: Definição do objetivo de performance

### Objetivo

Clarificar qual resultado está sendo avaliado e por quê.

### Instrução original

Informe objetivo, período e indicadores disponíveis.

### Prompt

Quero analisar indicadores e performance de forma estruturada.

Objetivo ou resultado esperado:
[INSIRA]

Período:
[INSIRA]

Indicadores disponíveis:
[LISTE]

Metas ou referências:
[INSIRA]

Contexto relevante:
[INSIRA]

Organize:
1. Resultado que está sendo avaliado
2. Indicadores realmente ligados ao resultado
3. Indicadores de contexto
4. Metas ou benchmarks existentes
5. Lacunas de informação
6. Riscos de interpretação
7. Perguntas de gestão que a análise deve responder.

## Etapa 2: Qualidade dos dados

### Objetivo

Verificar se os dados permitem conclusões confiáveis.

### Instrução original

Cole os dados disponíveis.

### Prompt

Antes de interpretar performance, avalie a qualidade dos dados.

Dados:
[COLE]

Analise:
1. Completude
2. Consistência
3. Período comparável
4. Definições dos indicadores
5. Mudanças de metodologia
6. Outliers
7. Dados faltantes
8. Possíveis vieses

Indique o que é confiável, o que exige cautela e o que precisa ser validado.

## Etapa 3: Leitura dos desvios

### Objetivo

Identificar variações relevantes versus meta, histórico ou referência.

### Instrução original

Use dados validados.

### Prompt

Analise os desvios de performance.

Dados validados:
[COLE]

Para cada indicador mostre:
1. Valor atual
2. Referência
3. Desvio
4. Tendência
5. Relevância
6. Se o desvio é material ou apenas ruído
7. Pergunta que o desvio gera

Não explique causas ainda. Primeiro descreva o que os dados mostram.

## Etapa 4: Hipóteses causais

### Objetivo

Levantar causas possíveis sem confundir correlação com causalidade.

### Instrução original

Use os desvios.

### Prompt

Com base nos desvios:
[COLE]

Levante hipóteses causais em:
1. Volume
2. Mix
3. Processo
4. Pessoas
5. Capacidade
6. Qualidade
7. Preço ou custo
8. Sazonalidade
9. Mercado
10. Mudanças operacionais

Para cada hipótese indique evidência a favor, evidência contra e dado necessário para confirmar ou descartar.

## Etapa 5: Segmentação da análise

### Objetivo

Encontrar onde a variação realmente está concentrada.

### Instrução original

Informe dimensões disponíveis.

### Prompt

Quero segmentar a performance para localizar concentrações.

Indicadores:
[COLE]
Dimensões disponíveis:
[EXEMPLO: REGIÃO, PRODUTO, CLIENTE, CANAL, EQUIPE, UNIDADE, PERÍODO]

Sugira cortes analíticos e organize:
1. Onde o problema ou ganho parece concentrado
2. Segmentos que puxam a média
3. Segmentos que mascaram o resultado
4. Comparações relevantes
5. Dados adicionais necessários

Não invente segmentações que não existam nos dados.

## Etapa 6: Priorização dos achados

### Objetivo

Separar o que exige ação do que exige investigação.

### Instrução original

Use análise consolidada.

### Prompt

Priorize os achados.

Achados:
[COLE]

Classifique cada um por:
1. Impacto
2. Urgência
3. Confiança da evidência
4. Controlabilidade
5. Risco de não agir

Separe em:
Ação imediata
Investigação prioritária
Monitoramento
Baixa prioridade

Explique o critério.

## Etapa 7: Plano de resposta gerencial

### Objetivo

Transformar os achados em ações e perguntas de gestão.

### Instrução original

Use prioridades.

### Prompt

Transforme os achados priorizados em um plano gerencial.

Para cada prioridade defina:
1. Ação ou investigação
2. Responsável sugerido
3. Dado necessário
4. Prazo
5. Indicador a acompanhar
6. Critério de sucesso
7. Ponto de revisão
8. Risco de agir com informação insuficiente.

## Etapa 8: Resumo executivo de performance

### Objetivo

Consolidar leitura, hipóteses e decisões em linguagem executiva.

### Instrução original

Use todas as etapas.

### Prompt

Crie um resumo executivo da performance.

Inclua:
1. Resultado geral
2. Principais indicadores
3. Desvios materiais
4. Tendências
5. Hipóteses causais
6. O que é fato versus hipótese
7. Prioridades
8. Ações ou investigações
9. Riscos
10. Próxima revisão

Evite conclusões causais sem evidência.

## Encerramento original

O loop deve transformar dados em questões gerenciais e decisões, sem criar causalidade fictícia.
•	Validar qualidade dos dados
•	Confirmar hipóteses com evidências
•	Definir prioridades
•	Executar ações ou investigações
•	Revisar indicadores após o ciclo
