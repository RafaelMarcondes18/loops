# Gestão de Riscos Empresariais

Roteiro do anexo fornecido por Rafael. Objetivos, instruções e prompts preservados; rótulos de interface removidos.

## Etapa 1: Escopo do risco

### Objetivo

Definir processo, projeto ou decisão a proteger.

### Instrução original

Descreva escopo e objetivos.

### Prompt

Quero estruturar uma análise de riscos empresariais.

Escopo:
[PROCESSO, PROJETO, ÁREA, DECISÃO OU OPERAÇÃO]

Objetivo:
[INSIRA]

Horizonte:
[INSIRA]

Contexto:
[INSIRA]

Delimite:
1. O que está dentro do escopo
2. O que está fora
3. Resultados que precisam ser protegidos
4. Stakeholders
5. Critérios de impacto
6. Informações faltantes.

## Etapa 2: Identificação de riscos

### Objetivo

Mapear eventos que podem comprometer objetivos.

### Instrução original

Use o escopo.

### Prompt

Mapeie riscos relacionados ao escopo:
[COLE]

Considere:
Operacional
Financeiro
Comercial
Regulatório
Jurídico
Pessoas
Fornecedor
Tecnologia
Dados
Reputação
Estratégia

Para cada risco descreva evento, causa, consequência e evidência. Não liste apenas temas genéricos.

## Etapa 3: Avaliação de probabilidade e impacto

### Objetivo

Priorizar riscos de forma consistente.

### Instrução original

Use riscos identificados.

### Prompt

Avalie os riscos:
[COLE]

Para cada um indique:
1. Probabilidade qualitativa
2. Impacto qualitativo
3. Velocidade de materialização
4. Detectabilidade
5. Evidência
6. Incerteza
7. Criticidade

Explique os critérios. Não use precisão numérica sem base.

## Etapa 4: Controles existentes

### Objetivo

Entender como os riscos já são tratados.

### Instrução original

Informe controles conhecidos.

### Prompt

Para cada risco:
[COLE]

Controles atuais:
[INSIRA, SE HOUVER]

Avalie:
1. Controle preventivo
2. Controle detectivo
3. Controle corretivo
4. Responsável
5. Evidência de funcionamento
6. Limitação
7. Risco residual
8. Lacuna de controle.

## Etapa 5: Dependências e concentração

### Objetivo

Identificar riscos sistêmicos e pontos únicos de falha.

### Instrução original

Use mapa de riscos.

### Prompt

Analise dependências entre riscos:
[COLE]

Procure:
1. Causas comuns
2. Fornecedor único
3. Pessoa chave
4. Sistema crítico
5. Dependência regulatória
6. Concentração de receita
7. Dependência de dado
8. Efeito cascata

Mostre quais riscos podem se amplificar mutuamente.

## Etapa 6: Tratamento de riscos

### Objetivo

Escolher respostas proporcionais.

### Instrução original

Use criticidade e controles.

### Prompt

Defina tratamento para riscos prioritários:
[COLE]

Opções:
Evitar
Reduzir
Transferir
Aceitar
Monitorar

Para cada risco indique:
1. Resposta recomendada
2. Ação
3. Responsável
4. Prazo
5. Custo ou esforço qualitativo
6. Benefício esperado
7. Risco residual
8. Critério de aceite.

## Etapa 7: Indicadores e gatilhos

### Objetivo

Criar sinais de alerta e governança.

### Instrução original

Use plano de tratamento.

### Prompt

Crie indicadores de risco para os riscos prioritários.

Para cada um:
1. Indicador
2. Fonte
3. Frequência
4. Limite ou sinal de alerta
5. Gatilho de escalonamento
6. Responsável
7. Decisão associada
8. Evidência que deve ser registrada.

## Etapa 8: Registro executivo de riscos

### Objetivo

Consolidar mapa e governança.

### Instrução original

Use todas as etapas.

### Prompt

Gere um registro executivo de riscos contendo:
1. Escopo
2. Riscos prioritários
3. Causas
4. Consequências
5. Probabilidade e impacto
6. Controles
7. Risco residual
8. Tratamento
9. Responsáveis
10. Indicadores
11. Gatilhos
12. Próxima revisão

Diferencie riscos confirmados, hipóteses e recomendações.

## Encerramento original

Gestão de riscos não é eliminar toda incerteza, mas tornar exposição, controles e decisões explícitos.
•	Validar riscos com responsáveis
•	Confirmar controles existentes
•	Priorizar tratamentos
•	Definir indicadores
•	Revisar periodicamente o risco residual
